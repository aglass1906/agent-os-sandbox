How to Play

  1. Press Start to launch a new game.
  2. Steer your ship with the Arrow keys or WASD: ←/A and →/D rotate, ↑/W thrusts.
  3. Hold/press Space to fire at the asteroids.
  4. Every asteroid you destroy scores points; survive each wave as the next one begins.
  5. You start with 3 lives. Losing all of them ends the game.
  6. On touch devices, use the on-screen buttons shown below the game area.
