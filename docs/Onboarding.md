# Welcome to Sandbox OS

Welcome aboard, and congratulations on joining the Sandbox OS project! We're thrilled to have you on the team as we build a safe, isolated environment where engineers can experiment, prototype, and run untrusted code with confidence. To help you hit the ground running, please start with the [README](../README.md), which is your definitive guide to the project's architecture, development workflow, coding conventions, and how to get your local environment up and running. Whether you're navigating the codebase for the first time or preparing your first contribution, the README will answer most of your questions; for everything else, don't hesitate to reach out to the team in the project channels where we're always happy to help. We're excited to see the impact you'll make here!
